# Subagent Governance Policy Reference

## Trust Levels
- **Low:** Minimal access for simple research.
- **Medium:** Access to non-sensitive project data.
- **High:** Access to core logic and implementation.
- **Admin:** Reserved for the primary operator.

## Prohibited Actions for Subagents
- Accessing secrets or credentials.
- Sending external messages.
- Deleting files or modifying core system configurations.
- Performing irreversible production changes.

## Recommended Use Cases
- Specialized research and data gathering.
- Code review and unit test generation.
- Summarization of long documents or logs.
- Documentation cleanup and formatting.
